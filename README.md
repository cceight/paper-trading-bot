# paper-trading-bot

米国株のペーパートレード(お金を使わない仮想売買)を、GitHub Actions で自動運用するボットです。
米国市場が開いている間、15分おきに起きて5分足を回収し、売買ルールに従って仮想口座で売買します。
成績は GitHub Pages のページで確認できます。
グラフには「実際の成績」「手数料と価格ズレを払う前の成績」「開始時にSPYを買って放置した場合」の3本を並べて、
ルールの実力とコストの重さを見分けられるようにしています。

## しくみ

- 起きるたびに、前回から今までの5分足をまとめて取得(起動が遅れても取りこぼしなし)
- 判断は足の終値で行い、約定は「次の足の始値」。価格ズレ(0.05%)と手数料(1株0.005ドル、最低1ドル)を差し引く
- 処理済みの時刻を保存しているので、起動のタイミングがバラバラでも結果は毎回同じ
- 初回起動時は過去データで売買せず、その瞬間から運用スタート
- 売買ルール(`bot/strategy.py`)と注文を出す部分(`bot/broker.py`)は分けてあるので、将来インタラクティブ・ブローカーズ等に移るときは注文部分の差し替えで済む

## セットアップ(最初の1回だけ)

1. GitHub で新しいリポジトリを作る(例: `paper-trading-bot`)。
   GitHub Pages を無料で使うには Public にする必要があります。
2. このフォルダの中身をすべてアップロードする(`.github` フォルダも忘れずに)。
3. リポジトリの Settings → Actions → General → Workflow permissions で
   「Read and write permissions」を選んで保存。
4. Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/docs` にして保存。
5. Actions タブ → `paper-trade` → 「Run workflow」で1回手動実行。
   これで運用開始。以降は平日の日本時間 22:00〜翌6:45 に15分おきに自動で動きます。

成績ページ: `https://<ユーザー名>.github.io/paper-trading-bot/`

## 設定を変えたいとき(`config.json`)

| 項目 | 意味 |
|---|---|
| `symbols` | 売買する銘柄。Anthropic が上場したらティッカーを足す |
| `benchmark` | 比較用に「買って放置」する銘柄(初期値 SPY) |
| `starting_cash_usd` | 仮想の開始資金 |
| `strategy.fast` / `slow` | 短期・長期の移動平均の本数(5分足で 12本=1時間、48本=4時間) |
| `costs` | 手数料と価格ズレ |

銘柄やルールを途中で変えると成績の比較がしにくくなるので、
仕切り直したいときは `state/` フォルダを消してから実行すると、まっさらな状態から再スタートします。

## 手元で動かす

```
pip install -r requirements.txt
python -m bot.run              # 1回分を実行
python -m bot.run --backtest   # 保存済みデータで「最初から運用していたら」の成績を表示
python -m tests.test_engine    # 起動タイミングで結果が変わらないことのテスト
```

## 注意

- 株価は Yahoo Finance から非公式に取得しています。無料で手軽な反面、仕様変更で取れなくなることがあります。
- GitHub Actions の定期実行は混むと遅れたり、まれに飛ばされたりします(次の回で取りこぼしは埋まります)。
- これは練習用の仮想売買です。ここで勝てても、本番で同じ成績になる保証はありません。
